■ スパイウェア関連

ある意味ウイルスより厄介なのがこのスパイウェアかもしれません。最近はかなり危険性が高い「トロイの木馬」などとの複合感染が増えています。ウイルス対策ソフトでは完全検出は困難なことが多いので、別途下記のようなツールを使う必要ありです。（最近ぼちぼち対応し出したようですけど）

とは言え、ウイルス・スパイウェアの区別なく（不正プログラムの）不正インストールの防止の基本は【Windows Update】と【ウイルス対策ソフト】です。この2点を守っていれば簡単にやられることはまずありません。でも「うっかりミス」もあるので下記のツール類で【保険】を掛けておくことをお奨めします。

あっと、【無料ソフト】や【無料の音楽系サイト】なども注意が必要ですね。

スパイウェアとは

「スパイウェアの定義」について、【アダルトサイト被害対策の部屋】さん。

「スパイウェア」の一般的なイメージとしてはクレジットカードの情報などを勝手に送信する危険なソフトの様に思われますが、広義（と言うよりは対策ベンダーによる業界用語的な分類）には情報送信しない「アドウェア」「ハイジャッカー」などの不正なプログラムやCookieなども含まれます。

アダルトサイト系として【Cool Web Search】などが有名ですが、実際には前述2点の基本的な対策をしていれば殆どの被害を避けることができます。でも、対策をしていなかった場合は「アドウェア」や「ハイジャッカー」だけでなく、超危険な「バックドア」なども放り込まれますのでご注意下さい。

  • スパイウェアについて知る - Microsoftのサイトより

多数の「複合感染」が発見された場合はすぐさま「リカバリー」をお奨めします。インターネットに接続するだけで情報漏洩などの危険があるからです。

■ いわゆる「エロ」対策

紳士の皆さんが一度は通る道ですか？（私もですが）
おすすめリンク（っていうか必読）
▼ スタートページをエロくされないための予防措置 by スキル相応のエロ推奨委員会さん

画像クリックしたら拡張子【exe】なファイルが落ちて来た～なんてのはほぼ確実に不正プログラムです。実行しちゃったらおしまいかも。わからない人はダウンロードは控えるべきだと思います～。最近はウイルススキャンで検出できないブツもいっぱーいありますから。

まず、ActiveX で絶対に「はい」を押しちゃダメ！

これ「セキュリティの警告」という画面が出るのですが、意味のわかってない方も多いみたいです。 「年齢認証」とか「動画を見るためのプラグイン」だとか装ってますがはっきり言ってほとんど「大ウソ」です。

エロサイトのこれはほぼ100％に近い確率で「スパイウェア」とか「ダイアラー」の類ですから...残念！。（ by hatayork 言うじゃなぁ～い♪）

「IE で突撃！」はやめといた方がいいです。

スクリプト・ActiveX 有効のまま（つまり通常設定）だとウイルス・スパイウェア連合軍から見れば 「飛んで鍋に入るネギしょったカモ」状態になってしまいます。

ちなみにウザいPopUpウィンドウも「スクリプト無効」にすれば出ません。「ActiveX無効」なら「セキュリティの警告」画面も出ませんから。

IE で攻めるならセキュリティ設定【高】が基本中の基本です。
これで、スクリプト・ActiveX・ダウンロードがすべて無効になります。

注意：「スクリプト無効」にしても メールストーム などのブラクラを防ぐ事はできません。（IE6 SP2 除く）

拡張子を安易に信用しない！

拡張子が【.mpg】【.jpg】だからといって安易にクリックしてはいけません。なぜならIE系ブラウザでは中身がウイルスだった場合、拡張子に関わりなく実行されてしまいます。また、別のアドレスに飛ばすことも簡単だからです。ダウンロードしてからウイルスチェックしましょう。（この際、拡張子が変っていないか、アイコンが偽装されていないか注意すること）これは「あやしい」サイトでなく、普通の掲示板などに貼られたリンクについても注意すべき事です。

IE のセキュリティ設定が【高】だとファイルのダウンロードも無効となっています。別途ダウンロードツールなどを使えば可能（または個別に設定）ですけど安全のために別のブラウザの使用をお奨めします。

Opera でスマートブラウジング

「Opera」で スクリプト＋プラグイン＋JAVA 無効で攻めるのがスマートかなと思います。

  • ActiveX がない
  • IE のセキュリティホールとは無関係
  • Mailto Storm などほとんどのブラクラが効かない

でも、Opera にもセキュリティホールがないわけではありません、油断は禁物です。なるべく最新バージョンを使用しましょう。また、あやしいものには手を出さないように...。

それでも、玉砕者が後を絶たない模様です。

「あれ、ページが開かないぞ」「ムフフな動画が見れないー」って時に セキュリティソフトを切ってしまうとか、IE のセキュリティ設定を【低】にしちゃうお莫迦なお方たちも多いみたいです。それこそ相手の思う壺です。【低】設定では ActiveX はバックグラウンドでの自動インストールになっちゃうんですけど...。

この「お莫迦」は昔の私だったりしますが...残念。

ダウンロード後のウイルスチェックは忘れずに。というか、あやしいサイトからダウンロードしたあやしいファイルの中にははウイルスチェックでも検出されないブツがゴロゴロあります。もともとあやしいものなら実行すべきではありません。

いわゆる「モロ」系サイトの2～3割以上はスパイウェア（またはウイルス）付なんじゃないかなと思います。ウイルス対策・スパイウェア対策ソフトでブロックできるのはあくまで「既知のコード」だけですから、ゆめゆめ油断などなさらぬように。「トロイ」なんか仕込まれちゃうと目も当てられませんからね。 ウイルス対策ソフト入れてないとか、Windows Updateしてなかったなんて言語道断ですよ。

「スクリプト無効」だと開かないページがあります。「Window Open」などで別ウィンドウを開くやつとかですね。「どうしても見たいんぢゃ」な方はページのソースを調べて下さい。そこにアドレス（ファイル名）が書かれていますので直打ちすれば見れます。（って推奨してるわけじゃないですよー）。
