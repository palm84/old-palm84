DirectWrite + Stylish Stylus

Firefox50 64bit にて、DirectWrite 設定に拡張機能 Stylish を追加してユーザースタイルシートを設定してみました。MacType 使用時に近い表示になりました。

【2018.8.4 追記】Stylish はやらかしたので下記の Stylus を使いませう。(´・ω・｀)

  • Stylus - Firefox 向けアドオン
  • Stylus - Chrome ウェブストア
  • Stylish :: Add-ons for Firefox
  • Stylish - Chrome ウェブストア
  • 拙作めも :
    • Firefox - DirectWrite + Stylish で MacType 風フォント表示にしてみる

Stylish 設定はとりあえずこれだけで。-webkit-text-stroke-width 及び text-shadow を設定。

body {
-webkit-text-stroke-width: 0.1px;
text-shadow: 0 0 1px rgba(0,0,0,0.1), 0 0 2px rgba(0,0,0,0.01), 0 0 3px rgba(0,0,0,0.01) !important;
}
