う～む

  • バックスラッシュ 0x5c = &#x5c; = \
    • font-family:'ＭＳ Ｐゴシック' = \
    • font-family:sans-serif = \
    • font-family:'Courier New',Courier = \

う～む、絶対確実な方法はないですねぇ。

  1. 確実に入ってそうな欧文フォントを指定する
    • Windowsなら Arial とかでいいけど、Times Courier New (Courier) あたりが無難？
  2. span 要素に lang="en" を指定する
    • IE や Opera では効かないかも？
    • 設定次第で逆にYenマークになっちゃうこともある？

でも、どのOSにも確実にある欧文フォントってあるかなぁ。Linuxでも標準設定がモナーフォントだとYenマーク（Yenサイン？）になりますし。

※ これとは逆に、バックスラッシュ (&#x5c; = \, &#92; or = \) としてでなく、
円マークとして確実に表示させるなら、実体参照 (&yen; = ¥)、 数値文字参照 (&#xa5; = ¥, or &#165; = ¥) を使いませぃ。

  • 参考：
    • バックスラッシュを入力したい：Windows ウィンドウズの使い方
    • バックスラッシュ - Wikipedia
font-family5CA5ゼロ(O)(i)(l)(Q)(I)あいうえお
無指定 \ ¥ 0 O i l Q I あいうえお
無指定 (lang="en") \ ¥ 0 O i l Q I あいうえお
Sans-serif \ ¥ 0 O i l Q I あいうえお
Sans-serif (lang="en") \ ¥ 0 O i l Q I あいうえお
Serif \ ¥ 0 O i l Q I あいうえお
Serif (lang="en") \ ¥ 0 O i l Q I あいうえお
Monospace \ ¥ 0 O i l Q I あいうえお
Monospace (lang="en") \ ¥ 0 O i l Q I あいうえお

※ 完全じゃないです。font-family は一つのみ指定してます。指定フォントがない環境では標準設定のフォントで表示されます。
