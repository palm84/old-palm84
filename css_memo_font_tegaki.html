これって何？

宛名書きなどに使うとよさそうな手書き風フォントを独断と偏見(笑)で選んでみました。

OpenType フォント（.otf ファイル）だと Windows でもそのままでブラウザ上でまぁまぁきれいに表示できます。TrueType（.ttf ファイル） フォントは IE などのブラウザでは綺麗に表示ができませんが印刷時は問題ないと思われます。

表示テストの項目については下記の通りです。

表示テストの項目
font-familyあいうえお漢字Windows \ ゼロオーアイ小文字エルQ濁点カナ漢字長音漢数字
無指定 あいうえお 葛噌彅埒一三髙濱片 Windows \ 0 O iI l Q プブ カ力エ工ロ口ー一ニ二

※ font-family:フォント名,serif と指定してます。指定フォントがない環境及び足りない漢字は（※ 多分）Serif 設定のフォントで表示されます。
