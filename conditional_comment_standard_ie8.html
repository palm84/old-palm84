コンディショナルコメント (IE8)【標準モード】

  • IE の標準モード = HTML 4.01 Transitional,URLあり
  • IE の後方互換モード = HTML 4.01 Transitional,URLなし
  • 【width 指定なし】
    • 標準モード 【pre要素に margin:0 5% 指定】
    • 互換モード 【pre要素に margin:0 5% 指定】
  • 【width 指定あり】
    • 標準モード - width 指定 【pre要素に margin:0 5%;width:90% 指定】
    • 互換モード - width 指定 【pre要素に margin:0 5%;width:90% 指定】
  • 標準モード【修正版】
  • 互換モード【修正版】[_width] 指定
  • 標準モード - 【コンディショナルコメント】（※書きかけ中）
  • 互換モード - 【コンディショナルコメント】

コンディショナルコメント

head要素内に記述する。IE5に別スタイルシート（IE6互換モード用）を適用。

link要素で通常CSSを指定、且つコメントでIE用CSSを指定する場合は、別適用ではなくIE用CSSで上書きとなるらしい。

<!--[if lt IE 6]>
<link rel="stylesheet" type="text/css" href="conditional_quirks_ie6.css" />
<![endif]-->
